# Alexi Dermosesian — Portfolio

Personal site for Alexi Dermosesian, a full-stack web developer in Yerevan, Armenia. It covers selected work, experience, technical stack, education and contact.

Live copy and project data live in `src/data.ts`.

## Stack

- React 19
- TypeScript
- Vite
- Framer Motion
- Lucide React
- Custom CSS (`src/styles.css`)

## Setup

Node.js 20 or later.

```bash
npm install
npm run dev
```

The app runs at [http://localhost:5173](http://localhost:5173). If that port is already in use:

```bash
npm run dev -- --port 5200 --strictPort
```

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Local development server |
| `npm run build` | Typecheck and production build |
| `npm run preview` | Serve the production build |
| `npm run lint` | ESLint |
